## Entry

`main.ts` writes a single funny line (200 characters or fewer) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, with exactly one trailing newline.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
